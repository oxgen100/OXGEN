## 当前 v0.3.2 的交互

新增主菜单 `4. Agent 安装（六款可选）`，六款按用户要求依次是 Codex、Claude Code、WorkBuddy、DeepSeek Harness、pi、OpenCode；子菜单 `7` 只读检测，`0` 返回主菜单。各项继续粘贴目录、一次确认，保留已有版本时不查网络；所有子页保持 `0` 返回。基础环境的一条龙只补 Git/Node/Python/VS Code，不自动安装全部 Agent。

按用户反馈重新对照上游主菜单和基础工具页：删除选盘和目录类型子菜单，直接粘贴路径；所有输入步骤使用 0 返回，确认页只保留 1 继续 / 0 返回。单项选择保留时不联网查询。主菜单增加一条龙直达入口，先检测全部环境，只为缺失/不完整组件准备安装计划，粘贴一次总目录，确认一次后连续安装并配置新组件 PATH。WSL 仍由独立菜单管理。

标题使用亮青色单行 `O X G E N`，五个大写字母间统一留空，下接中文名与版本。Windows 自主执行期间输入 0 并回车取消后续操作；输入读取器在取消与下一次菜单之间保留同一个未完成读取，避免退出键被后台任务吞掉。系统权限和 Apple 安装窗口使用系统自身的取消操作。

## 前期实现沿革

这次改版仅涉及终端呈现和菜单切换。安装器、官方来源、路径选择规则及 WSL 机制继续使用原实现。用 Go 独立实现菜单风格，不引入或运行上游 Bash 脚本。

主菜单提供 Agent 基础环境、本机环境检测、一条龙安装三个入口；子菜单提供各组件单独管理。

v0.1.2 按用户要求加入 `6. VS Code 检测／安装／更新`，同时纳入统一环境引导；其他编号与界面风格保持一致。

菜单示意（此处纯文本不包含颜色）：

```text
O X G E N
氧气邮政员 v0.3.2
命令参考：oxgen / oxgen doctor
------------------------
1.   Agent 基础环境
2.   本机环境检测
3.   一条龙安装（只补缺失环境）
4.   Agent 安装（六款可选）
------------------------
0.   退出脚本
------------------------
请输入你的选择:
```

`oxgen` 命令需要用户选择加入 PATH；本地测试包仍可以直接双击启动。上面的“命令参考”不会宣称用户已配置快捷入口。

交互终端在打开或切换菜单时清屏；CLI 只读检测不清屏，重定向输出和管道输入也不发送清屏码、不等待结果确认。`--no-color`、`NO_COLOR` 继续关闭颜色，`TERM=dumb` 关闭终端控制。结果页使用 0 返回，也兼容直接回车；保持标准行输入。
